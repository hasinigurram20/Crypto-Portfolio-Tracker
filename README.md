## 🚀 Project Overview

The **Crypto Portfolio Tracker** is a Java-based application designed to help users manage and monitor their cryptocurrency portfolio.

The application allows users to add cryptocurrencies, record the quantity owned and purchase price, view their portfolio, calculate the total investment, and track the current value of their holdings.

---

## ✨ Features

* 🪙 **Add Cryptocurrency** – Add cryptocurrency details such as name, quantity, and price.
* 📋 **View Portfolio** – Display all cryptocurrencies in the portfolio.
* ✏️ **Update Holdings** – Modify cryptocurrency quantity or price details.
* 🗑️ **Delete Cryptocurrency** – Remove a cryptocurrency from the portfolio.
* 💰 **Investment Calculation** – Calculate the total amount invested.
* 📊 **Portfolio Value** – Calculate the current value of cryptocurrency holdings.
* 🔍 **Search Cryptocurrency** – Search for a specific cryptocurrency.
* 📈 **Profit/Loss Calculation** – Calculate the profit or loss based on purchase and current prices.
